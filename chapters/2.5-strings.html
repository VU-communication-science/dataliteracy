2.5 String Processing with stringr

Working with text variables, pattern matching, and cleaning strings in the tidyverse

Introduction

In communication science, much of the data we work with contains text: survey open-ended responses, headlines, social media posts, or category codes that need standardization. Before conducting computational content analysis, we often need basic tools to inspect, clean, and manipulate character strings.

The stringr package (part of the core tidyverse) provides a consistent and friendly set of functions for string manipulation, where all functions start with str_.

NoteRequired Packages 
library(tidyverse)

Basic String Operations

Let’s create a small example vector of news headlines:

headlines <- c(
  "Breaking: Prime minister announces new climate policy!",
  "Economy shows modest growth in Q3",
  "Breaking: New survey reveals rising public concern over inflation",
  "Local election debate ends in stalemate"
)
headlines
[1] "Breaking: Prime minister announces new climate policy!"           
[2] "Economy shows modest growth in Q3"                                
[3] "Breaking: New survey reveals rising public concern over inflation"
[4] "Local election debate ends in stalemate"

Detecting Patterns: str_detect()

str_detect() tests whether a string matches a pattern, returning TRUE or FALSE. It is frequently used inside filter():

str_detect(headlines, "Breaking")
[1]  TRUE FALSE  TRUE FALSE

To make searches case-insensitive, wrap the pattern in regex(..., ignore_case = TRUE):

str_detect(headlines, regex("election", ignore_case = TRUE))
[1] FALSE FALSE FALSE  TRUE

Extracting Patterns: str_extract()

str_extract() pulls out the first matching pattern:

str_extract(headlines, "Q[1-4]")
[1] NA   "Q3" NA   NA

Replacing Patterns: str_replace() and str_replace_all()

str_replace() replaces the first match, while str_replace_all() replaces every occurrence:

str_replace(headlines, "Breaking: ", "")
[1] "Prime minister announces new climate policy!"           
[2] "Economy shows modest growth in Q3"                      
[3] "New survey reveals rising public concern over inflation"
[4] "Local election debate ends in stalemate"

Modifying Case and Whitespace

Common data cleaning tasks involve standardizing casing and trimming unnecessary whitespace:

dirty_text <- c("  United Nations ", "EU ", " climate change  ")

str_trim(dirty_text)
[1] "United Nations" "EU"             "climate change"
str_to_lower(dirty_text)
[1] "  united nations " "eu "               " climate change  "

Using stringr inside Data Frames

In practice, string operations are most powerful inside mutate() and filter():

df <- tibble(
  title = headlines,
  source = c("Daily News", "Financial Times", "Daily News", "Metro")
)

df |> 
  filter(str_detect(title, "Breaking")) |> 
  mutate(clean_title = str_replace(title, "Breaking: ", ""))
# A tibble: 2 × 3
  title                                                       source clean_title
  <chr>                                                       <chr>  <chr>      
1 Breaking: Prime minister announces new climate policy!      Daily… Prime mini…
2 Breaking: New survey reveals rising public concern over in… Daily… New survey…
