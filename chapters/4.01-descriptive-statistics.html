4.1 Descriptive Statistics

Descriptive statistics and data exploration.

You arrive here from Grouping and summarizing and Correlation & Covariance, so you can already compute summaries per group and describe how two variables relate. Here you’ll learn which descriptive statistic fits which type of variable — frequencies for categories, central tendency and spread for numbers — and how to standardize a numeric variable into z-scores so it is comparable across different scales. Describing your data well like this is the first thing you do in any analysis, and it tells you which methods fit your data later on.

→ See this module in the skill tree

4.1.1 Describing variables

We’ll use the same practice dataset throughout this chapter:

library(tidyverse)
d <- read_csv("https://dev.dataliteracy.cc/practice_data.csv")

Not every variable can be described the same way. A categorical variable (like political_orientation, with values such as “left”, “center”, “right”) only has counts and proportions — it makes no sense to compute its “average”. A numeric variable (like political_interest or age) can also be summarized with central tendency (where is the middle?) and spread (how much do values differ from each other?).

Categorical variables: frequencies

For a categorical variable, the most useful summary is a frequency table: how many (and what proportion of) observations fall into each category. The tidyverse way to do this is count(), optionally followed by computing percentages:

d |>
  count(experiment_group) |>
  mutate(percent = round(100 * n / sum(n), 1))

This immediately tells you whether your groups are balanced, and whether any category is so rare that it might cause trouble later (e.g. too few observations to compare groups reliably).

Numeric variables: central tendency

For a numeric variable, central tendency answers “what’s a typical value?”. The three common measures are:

  • Mean: the arithmetic average, mean(). Sensitive to extreme values (outliers).
  • Median: the middle value when sorted, median(). Robust to outliers — useful for skewed variables like income.
  • Mode: the most frequent value. R has no built-in mode() function for this (that name is already taken for something else), but for most purposes a frequency table like above already shows you the mode (the category with the highest n).
mean(d$political_interest)
[1] 3.863764
median(d$political_interest)
[1] 3.849327

Here the mean and median are close, which suggests political_interest is reasonably symmetric. When mean and median differ a lot, that’s a sign of a skewed distribution — worth a look with a histogram before you decide which measure to report.

Numeric variables: spread

Central tendency alone can be misleading — two variables can have the same mean but look very different. Spread (or dispersion) describes how much the values vary:

  • Range: the distance between the minimum and maximum, range().
  • Standard deviation (sd()) and variance (var()): how far values typically fall from the mean, on average. Covered in detail in Means & Variance.
  • Interquartile range (IQR): the range of the middle 50% of the data, IQR(). Like the median, it’s robust to outliers.
range(d$political_interest)
[1] 1 7
sd(d$political_interest)
[1] 1.045567
IQR(d$political_interest)
[1] 1.384123

A handy shortcut that reports several of these at once is summary():

summary(d$political_interest)
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
  1.000   3.215   3.849   3.864   4.600   7.000

4.1.2 Standardizing variables

What is standardization?

Standardization is a technique for transforming data into a consistent scale. It involves two key components: centering and scaling.

  • Centering shifts the data so that its mean becomes zero.
  • Scaling adjusts the data’s range by dividing it by the standard deviation.

The result is that the data is transformed to have a mean of zero and a standard deviation of one. We then also refer to the values of the transformed data as z-scoreds. Standardizing a variable to z-scores has a number of benefits, and you’ll see that we use standardization in different contexts throughout this book:

  • Interpretability: Standardized variables can be interpreted in the same way. Since zero is the mean, positive values indicate that the observation is above average, and negative values indicate that it is below average. A value of 1 means that the observation is one standard deviation above the mean.
  • Comparability: Standardization allows you to compare variables that have different units or scales. It allows us to compare age and income, even if one is measured in years and the other in euros.
  • Correlation analysis: If you calculate the covariance of two standardized variables, you get the correlation coefficient, which is a useful measure of the strength and direction of the relationship between two variables.
  • Multiple regression: Standardization can help you compare the strength of the effects of different independent variables in a multiple regression model.

How to standardize variables

Let’s first create a simple numeric variable x with some values, and calculate its mean and standard deviation.

x <- c(4, 9, 6, 3, 9, 10)

mean(x)
[1] 6.833333
sd(x)
[1] 2.926887

To standardize it, we subtract the mean (\(\bar{x}\)) from each value, and then divide by the standard deviation (\(S_x\)): \[ z = \frac{x - \bar{x}}{S_x} \]

You can think of this process as shifting the center and stretching the scale of the data. By subtracting the mean, we shift the center so that the mean becomes zero. By dividing by the standard deviation, we stretch (or squeeze) the scale so that the standard deviation becomes one. Try changing the mean and standard deviation in this widget to see this shifting and stretching in action:

viewof numberLine = Inputs.range(
  [0, 6.83],
  {value: 6.83, step: 0.01, label: "MEAN"}
)
viewof standardDeviation = Inputs.range(
  [1, 2.93],
  {value: 2.93, step: 0.01, label: "SD"}
)

 {
  const width = 600;
  const height = 150;
  const margin = { left: 50, right: 50, top: 20, bottom: 20 };

  const meanValue = numberLine;
  const stddevValue = standardDeviation;

  // Scale based on mean and standard deviation
  const scaleX = d3.scaleLinear()
      .domain([meanValue-10 * stddevValue/5, meanValue+10 * stddevValue/5])
      .range([margin.left, width - margin.right]);

  const axis = d3.axisBottom(scaleX)
      .ticks(10);

  const svg = d3.create("svg")
      .attr("width", width)
      .attr("height", height);

  // Draw the number line axis
  svg.append("g")
      .attr("transform", `translate(0, ${height / 2})`)
      .call(axis);

  // Add some data points centered around the mean
  const dataPoints = [meanValue - stddevValue, meanValue, meanValue + stddevValue];
  const labels  = ["-1 SD", "Mean", "+1 SD"];

  svg.selectAll(".dot")
      .data(dataPoints)
    .enter().append("circle")
      .attr("class", "dot")
      .attr("cx", d => scaleX(d))  // Position based on scaled value
      .attr("cy", height / 2)      // Place them on the number line
      .attr("r", 5)
      .attr("fill", "red");

  // Label the points
  svg.selectAll(".label")
      .data(dataPoints)
    .enter().append("text")
      .attr("x", d => scaleX(d))
      .attr("y", height / 2 - 10)
      .attr("text-anchor", "middle")
      .text((d,i) => labels[i]);

  return svg.node();
}

Now let’s do this in R.

z <- (x - mean(x)) / sd(x)

mean(z)
[1] 9.253666e-17
sd(z)
[1] 1

As you can see, the mean and standard deviation are now zero1 and one, respectively. But other than that, the distribution of the data is the same! You can see that they’re perfectly correlated:

cor(x, z)
[1] 1

Alternative: use the scale() function

There is also a built-in function in R that standardizes variables for you. This function is called scale().

scale(x)
           [,1]
[1,] -0.9680365
[2,]  0.7402632
[3,] -0.2847166
[4,] -1.3096965
[5,]  0.7402632
[6,]  1.0819232
attr(,"scaled:center")
[1] 6.833333
attr(,"scaled:scale")
[1] 2.926887

This actually gives us a bit more than we need2. To just get a vector of z-scores, we can wrap the scale() function in as.vector().

as.vector(scale(x))
[1] -0.9680365  0.7402632 -0.2847166 -1.3096965  0.7402632  1.0819232

We can use this as follows to standardize a variable in a tibble:

library(tidyverse)

tibble(x=x) |>
  mutate(x_z = as.vector(scale(x)))

Footnotes

  1. Note that instead of a clean zero, you might see a weird number like 9.253666e-16. This is because computer’s have limited precision, and in this case the best it could to is to get reaaaaally close to zero. The number is in scientific notation, which is used to express really small or really large numbers. The notation can be read as: \(9.253666 \times 10^{-17}\).↩︎

  2. The scale() function doesn’t just return the z-scores, but also the mean and standard deviation. Also, the z-scores are returned as a matrix, which is similar but different from a vector. This can cause issues in some functions. Wrapping it in as.vector() ensures that we only get a vector with the z-scores.↩︎
