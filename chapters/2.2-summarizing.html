2.2 Summarizing Data

Aggregating and grouping data with dplyr

Data Summarization

The functions used in earlier parts on data preparation worked on individual rows. Sometimes, you need to compute properties of groups of rows (cases). This is called aggregation (or summarization) and in the tidyverse uses the group_by function followed by either summarize or mutate.

NoteRequired packages and data 
library(tidyverse)
url <- "https://raw.githubusercontent.com/fivethirtyeight/data/master/poll-quiz-guns/guns-polls.csv"
d <- read_csv(url) |>
  select(-URL) |>
  rename(Rep = `Republican Support`, Dem = `Democratic Support`)

Summarizing

To summarize grouped data, follow group_by with a call to summarize. The syntax is summarize(column = calculation, ...). Crucially, the calculation must compute a single summary value given a vector of values. Very common summarization functions are mean(), sd(), median(), and n().

For example, the following computes the average support per question:

d |>
  group_by(Question) |>
  summarize(Support = mean(Support, na.rm = TRUE)) |>
  arrange(desc(Support))
# A tibble: 8 × 2
  Question                    Support
  <chr>                         <dbl>
1 background-checks              87.4
2 mental-health-own-gun          85.8
3 age-21                         75.9
4 ban-high-capacity-magazines    67.3
5 stricter-gun-laws              66.5
6 ban-assault-weapons            61.8
7 arm-teachers                   42  
8 repeal-2nd-amendment           10

summarize reduces the rows equal to the number of groups (8), keeping only the grouping variables and the newly calculated summary columns.

You can also compute summaries of multiple values:

d |>
  group_by(Question) |>
  summarize(
    Dem = mean(Dem, na.rm = TRUE),
    Rep = mean(Rep, na.rm = TRUE),
    diff = mean(Dem - Rep, na.rm = TRUE)
  ) |>
  arrange(desc(diff))

Another essential helper is n() (without arguments), which counts the number of rows in each group:

d |>
  group_by(Question) |>
  summarize(
    n = n(),
    mean = mean(Support, na.rm = TRUE),
    sd = sd(Support, na.rm = TRUE)
  )

Using mutate with group_by

While summarize collapses multiple rows into a single summary row, using mutate after group_by preserves all rows and adds the group-level summary as a new column:

d2 <- d |>
  group_by(Question) |>
  mutate(
    avg_support = mean(Support, na.rm = TRUE),
    diff = Support - avg_support
  )

Ungrouping

Finally, you can use ungroup() to remove grouping metadata. When you are done computing grouped operations, calling ungroup() ensures subsequent functions treat the data frame as a single whole:

d2 |>
  ungroup() |>
  summarize(overall_sd = sd(diff, na.rm = TRUE))
# A tibble: 1 × 1
  overall_sd
       <dbl>
1       5.19
